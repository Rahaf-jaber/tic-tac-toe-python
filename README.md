# Tic Tac Toe Game — Python OOP

A two-player Tic Tac Toe game built using Python and Object-Oriented Programming (OOP).

## Features

- Two-player gameplay.
- Custom player names and symbols.
- Interactive console-based game board.
- Input validation for player names, symbols, and moves.
- Automatic win and draw detection.
- Option to restart or quit the game.

## OOP Concepts

The project is organized into four classes:

- **Player:** Manages player names and symbols.
- **Menu:** Handles the main menu and end-game options.
- **Board:** Displays, updates, validates, and resets the game board.
- **Game:** Controls the game flow, player turns, and win/draw detection.

## How to Run

Make sure Python is installed, then run:

```bash
python tic_tac_toe.py
```
